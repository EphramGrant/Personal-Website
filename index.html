Coding · Basics

Basics.

There are many differences between programming languages, but all of them utilize most or all of these concepts to varying degrees.

Variables & Data Types

Storing information is key to creating programs. This allows you to save data, perform operations on it, and transfer it to other parts of your code. The types of variables available and how they are used vary throughout languages but generally there are a few consistent types.
Integers: Whole numbers (positive/negative). Often shortened as int.
Strings: A collection of symbols/characters. Stores words or phrases.
Floats: Decimal number. Often have different types based on the number of digits after the .
Character: A single character. Some languages just count it as a string. Often shortened to Char.
Boolean: A true or false value. Often shortened to bool.

Control Flow

Control flow determines what code runs and when. Without it your program would run top to bottom and always do the same thing. The core tool is the conditional statement.
If: Runs a block of code if a condition is true.
Else: Runs if the condition is false.
Else If: Checks another condition if the previous one was false. You can chain as many as needed.
Conditions use comparison operators: == (equal), != (not equal), >, <, >=, <=. Combine them with && (and), || (or), ! (not).

Loops

Loops repeat a block of code multiple times without writing it out repeatedly. There are two main types found across most languages.
For Loop: Repeats a set number of times. Used when you know how many iterations you need, such as going through every item in a list.
While Loop: Runs as long as a condition is true. Used when you don't know how many iterations you need, such as waiting for user input. Be careful — if the condition never becomes false you'll create an infinite loop that freezes your program. For example, if I write a while loop that will continue looping until x > 10 and x never changes, the program will continue running until it crashes.

Functions

A function is a reusable block of code that performs a specific task. You can define it once and call it whenever you need it instead of writing the same logic repeatedly.
Parameters: Inputs passed into a function that change how it behaves.
Return: A value sent back to wherever the function was called from. Functions that don't explicitly return and anything just perform an action. often return a value with no information such as a void, null, or none.
Helper Functions: A function that is used inside of another function. Good functions do one thing, do it well, and have a clear name describing what that thing is. For example, I can have an "Add" function that takes into two numbers as parameters and returns their sum. It is considered bad practice to also have this function multiply. Instead, create multiple functions and use the specific function when its specific task is needed, including inside other functions.

Arrays & Collections

Arrays and collections store multiple values in a single variable. Items are accessed by position, called an index. Most languages index from 0, so the first item is at index 0.
Arrays: Fixed-size ordered lists. Size is set when created and cannot change. These are useful when you know the exact amount of items in advance.
Lists: Work like arrays but can grow and shrink as you add or remove items. These often have downsides compared to Arrays such as being slower and should generally only be used if necessary.
Dictionaries: Store key-value pairs instead of indexed items. These are unordered. You look up a key to get its associated value, similar to a real dictionary. For example, I can search the dictionary for "Hello" (key) and it would return whatever value is stored under "hello" such as the definition of the word (value).

Object-Oriented Programming

Object-Oriented Programming (OOP) structures code around objects — bundles of related data and behaviour. Most modern languages support it, and some explicitly require it.
Class: A blueprint defining what an object looks like and what it can do.
Object: A specific instance created from a class. A Dog class defines that all dogs have a name and can bark — each individual dog you create is an object.
Creating classes allows you to separate your code effectively. This is very important because it can cause issues if your code is linked in a single program

Variable Scope

Variables are generally defined to the place where they were created. Variables that were created inside of a function or loop can usually not be accessed outside of these locations. The place where a variable can be used is called its scope. A variable that is usable anywhere in the program has global scope. Many languages have ways to define global variables, but these are generally frowned upon and considered bad practice to use. This is because the entire program being able to change a value makes tracking bugs extremely difficult. This problem compounds as programs get bigger, so I recommend making sure you build habits of not using it as soon as possible.

Challenges

Each language section on this site includes challenges at the end of every topic. These are short practical exercises to reinforce what you just read with practice tasks. The best way to learn programming is to actually write code, not just read about it.

To complete them you have a few options.
IDE: An IDE (Integrated Development Environment) is a program that lets you write, run, and debug code. Good free options are VS Code (works for everything) or PyCharm for Python specifically. IDE's often come with many helpful extensions or features such as autocompleting text and clearly highlighting errors. Use Youtube to find videos on setting up an IDE.
Browser: No setup required. Sites like Replit let you write and run code directly in your browser for free.
Notepad: You can write code in any online text editor. This works fine for simple exercises, but is generally unintuitive.
Paper: Perfectly valid for tracing through logic and understanding what code does before you run it. Known as "tracing" or "desk checking". This is convenient and easy to do, but you can't run your code to check for small errors.

Coding · Python

Python.

Python resources and guides for beginners and intermediates.

Getting Started

Python is designed to be readable. It uses indentation to define blocks or sections of code, instead of curly braces like many languages. No semicolons are used at the end of lines, another common requirement (and source of frustration) in many languages. There are also no type declarations (Python figures out that 5 is an integer without you having to tell it). It's the most beginner-friendly language to start with.

Data Types & Variables

int: Whole numbers.
float: Decimal numbers.
str: Text in single or double quotes.
bool: True or False.
None: Represents the absence of a value.
Regular variable names are conventionally lowercase with an underscore between words. Constants, or named specific bits of information that do not change are often fully capitalized with underscores between words.

Python
name = "Ephram"
age = 21
height = 5.11
is_student = True
nothing = None
EYE_COLOR = "Brown"

print(type(age))
x, y, z = 1, 2, 3  # multiple assignment

Control Flow

Indentation defines the block. No curly braces are needed. Colon is required after every condition.
elif: Python's version of else if.
match (3.10+): Checks one variable against multiple values, similar to switch in other languages.

Python
score = 75

    print("A")
elif score >= 70:
    print("B")
else:
    print("C or below")

# Match (Python 3.10+)

match day:
    case "Monday": print("Start of the week")
    case "Friday": print("End of the week")
    case _: print("Midweek")

Functions

Defined with def. Can have default parameter values and return multiple values.
Lambda: A one-line anonymous function for simple operations.

Python

    return f"{greeting}, {name}!"

print(greet("Ephram"))         # Hello, Ephram!
print(greet("Ephram", "Hey")) # Hey, Ephram!

# Multiple return values
def min_max(nums):
    return min(nums), max(nums)

lo, hi = min_max([3, 1, 9, 4])

# Lambda

print(square(5))  # 25

Classes & OOP

__init__ is the constructor, runs when a new object is created. self refers to the instance and must be the first parameter of every method.
Inheritance: Pass the parent class in parentheses. Use super() to call the parent's methods.
Dunder methods: __str__, __len__ etc. define how objects behave with built-in operations.

Python
class Animal:
    def __init__(self, name, sound):
        self.name = name
        self.sound = sound

    def speak(self):
        return f"{self.name} says {self.sound}"

    def __str__(self):
        return self.name

class Dog(Animal):
    def __init__(self, name):
        super().__init__(name, "woof")

dog = Dog("Rex")
print(dog.speak())  # Rex says woof
Challenge

Create a Car class with make, model, and year attributes. Add a method called description that returns a string like "2020 Toyota Camry". Create two car objects and print their descriptions.

Python
class Car:
    def __init__(self, make, model, year):
        self.make = make
        self.model = model
        self.year = year

    def description(self):
        return f"{self.year} {self.make} {self.model}"

Libraries & Packages

Install third-party libraries with pip install package-name. Import at the top of your file.
import: Imports an entire module.
from … import: Imports only what you need.
as: Gives an import a shorter alias.

Python
import math
print(math.sqrt(16))  # 4.0

from random import randint
print(randint(1, 10))  # random 1–10

# Common third-party (pip install first)
import numpy as np   # numerical computing
import pandas as pd  # data analysis
import requests       # HTTP requests

Coding · Java

Java.

Java programming resources covering core concepts and OOP.

Getting Started

Java is strongly typed and verbose — every variable must have a declared type, every statement ends with a semicolon, and all code lives inside a class. It's more strict than Python but that strictness makes errors easier to catch early.

Variables: Type must be declared before the name.

Java
// Variables
String name = "Ephram";
int age = 21;
double height = 5.11;
boolean isStudent = true;

Functions: Called methods in Java. Must declare a return type — use void if nothing is returned.

Java
public String greet(String name) {
    return "Hello, " + name;
}

System.out.println(greet("Ephram"));  // Hello, Ephram

Control Flow: Condition must be in parentheses. Curly braces define the block.

Java
int score = 75;

if (score >= 90) {
    System.out.println("A");
} else if (score >= 70) {
    System.out.println("B");
} else {
    System.out.println("C or below");
}

Loops: for loops declare a counter variable, a condition, and an increment all in one line.

Java
// For loop
for (int i = 0; i < 5; i++) {
    System.out.println(i);  // 0 1 2 3 4
}

// While loop
int count = 0;
while (count < 3) {
    System.out.println(count);
    count++;
}

Coding · JavaScript

JavaScript.

JavaScript for web development, scripting, and beyond.

Getting Started

JavaScript runs in the browser and is the primary language of the web. It's loosely typed — variables can hold any type and change type freely. Use let for variables that change and const for ones that don't. Avoid var; it has scoping quirks that cause bugs.

Variables:

JavaScript
// Variables
const name = "Ephram";
let age = 21;
let height = 5.11;
const isStudent = true;

Functions: Two common ways to define them — traditional and arrow functions. Arrow functions are shorter and more common in modern JavaScript.

JavaScript
// Traditional
function greet(name) {
    return "Hello, " + name;
}

// Arrow function
const greet = (name) => "Hello, " + name;

console.log(greet("Ephram"));  // Hello, Ephram

Control Flow: Same syntax as Java — parentheses around condition, curly braces for the block.

JavaScript
let score = 75;

if (score >= 90) {
    console.log("A");
} else if (score >= 70) {
    console.log("B");
} else {
    console.log("C or below");
}

Loops:

JavaScript
// For loop
for (let i = 0; i < 5; i++) {
    console.log(i);  // 0 1 2 3 4
}

// While loop
let count = 0;
while (count < 3) {
    console.log(count);
    count++;
}

Coding · C#

C#.

C# programming for applications, games, and more.

Getting Started

C# is strongly typed like Java but with cleaner syntax. It's the primary language for Unity so if you're here for game development this is where to focus. Every variable needs a declared type, every statement ends with a semicolon, and all code lives inside a class.

Variables:

C#
// Variables
string name = "Ephram";
int age = 21;
float height = 5.11f;  // f suffix marks it as a float
bool isStudent = true;

Functions: Called methods in C#. Must declare a return type — use void if nothing is returned. Access modifiers (public, private) control visibility.

C#
public string Greet(string name) {
    return "Hello, " + name;
}

Debug.Log(Greet("Ephram"));  // Hello, Ephram

Control Flow: Same syntax as Java — parentheses around condition, curly braces for the block.

C#
int score = 75;

if (score >= 90) {
    Debug.Log("A");
} else if (score >= 70) {
    Debug.Log("B");
} else {
    Debug.Log("C or below");
}

Loops:

C#
// For loop
for (int i = 0; i < 5; i++) {
    Debug.Log(i);  // 0 1 2 3 4
}

// While loop
int count = 0;
while (count < 3) {
    Debug.Log(count);
